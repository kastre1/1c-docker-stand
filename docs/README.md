## 🔧 Как использовать документацию

### В Obsidian (рекомендуется)

Obsidian — это редактор заметок на основе Markdown. Он красиво рендерит документы и строит граф связей между ними.

1. **Скачайте** Obsidian: [https://obsidian.md](https://obsidian.md)
2. **Откройте папку `docs/`** как vault:
   - `Open folder as vault` → выберите `~/projects/1c-server/docs/`
3. **Начните** с этого файла (`README.md`)

**Плюсы Obsidian:**
- Красивый рендеринг Markdown
- Граф связей между документами
- Быстрый поиск
- Тёмная тема

### На GitHub

GitHub тоже рендерит Markdown, но без Obsidian-фишек. Документация будет читаться прямо на сайте.

### В любом Markdown-редакторе

VS Code, Typora, Marktext — все откроют `.md`-файлы корректно.
