# Стенд 1С:Предприятие + PostgreSQL в Docker

**Автор:** kastrel  
**Дата:** 2026-09  
**Статус:** рабочий стенд ✅

> Отказоустойчивый тестовый стенд для разработки и отладки решений на базе 1С:Предприятие 8.3, полностью развёрнутый в Docker на Linux-хосте. Подходит как для учебных задач, так и для реальной разработки в условиях франчайзи.

---

## 🎯 Что это

Полностью контейнеризованный стенд **«1С:Предприятие 8.3.26.1540 + PostgreSQL 15.17-1.1C»**, развёрнутый на Ubuntu VM внутри VirtualBox. Все компоненты работают в Docker, доступны с Windows-хоста по сети.

**Ключевые компоненты:**

- 🐘 **PostgreSQL 15.17-1.1C** — официальная сборка от 1С с расширениями `mchar`, `fasttrun`
- 🏢 **Сервер 1С 8.3.26.1540** — кластер серверов (`ragent`, `rmngr`, `rphost`)
- 🎨 **X11 через TCP (VcXsrv)** — для GUI-операций внутри контейнеров
- 🔑 **Community-лицензия** — активирована на контейнер 1С-сервера
- 🖥️ **Тонкий клиент 1С на Windows** — подключается к серверу по сети

## 🚀 Быстрый старт

**Для тех, кто уже знаком с Docker и 1С** — короткая последовательность:

```bash
# 1. Клонировать репозиторий
git clone <url> && cd 1c-docker-stand

# 2. Скачать дистрибутивы с releases.1c.ru:
#    - setup-full-8.3.26.1540-x86_64.run → 1c-server/distr/
#    - postgresql_15.17_1_ubuntu_24.04_x86_64_package.tar.bz2 → postgres/distr/
#    - postgresql_15.17_1_ubuntu_24.04_x86_64_package_addon.tar.bz2 → postgres/distr/

# 3. Распаковать .deb для PostgreSQL
cd postgres/distr && tar -xjf *.tar.bz2 && mkdir -p ../distr-min
cp postgresql-15_*.deb libpq5_*.deb postgresql-client-15_*.deb \
   postgresql-client-common_*.deb postgresql-common_*.deb ../distr-min/
cd ../..

# 4. Запустить
docker compose build
docker compose up -d
docker compose ps
```

**Подробная пошаговая инструкция** — в [`docs/02-vm-setup.md`](docs/02-vm-setup.md) и далее.

## ⚠️ Известные особенности

1. **Community-лицензия привязана к MAC контейнера.** Не пересоздавайте `1c-server` без необходимости. Подробнее — в [`docs/07-license.md`](docs/07-license.md).
2. **Для GUI-операций нужен X-сервер на Windows** (VcXsrv или MobaXterm). См. [`docs/05-x11-forwarding.md`](docs/05-x11-forwarding.md).
3. **Тонкий клиент на Windows требует записи в `hosts`** для резолва имени контейнера. См. [`docs/08-thin-client.md`](docs/08-thin-client.md).
